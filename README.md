# 📊 Data Analytics & Business Intelligence Dashboard

A full-stack Data Analytics and Business Intelligence Dashboard built to analyze sales data, monitor business KPIs, visualize trends, and generate useful business reports.

The system provides interactive dashboards, charts, filters, search functionality, CSV data import/export, PDF report generation, and top-selling product analysis.

---

## 🚀 Project Overview

The Data Analytics & Business Intelligence Dashboard is a web-based analytics application that helps users understand business sales performance through interactive visualizations and key performance indicators.

The application connects a React.js frontend with a Node.js/Express.js backend and PostgreSQL database.

Users can:

- Monitor total sales
- Track total orders
- Track total quantity sold
- Calculate average sale value
- Analyze sales by category
- Analyze sales by region
- Monitor monthly sales trends
- Filter data by category
- Filter data by month
- Search sales records
- View sales data in a table
- Navigate through paginated records
- Import sales data using CSV
- Export sales data as CSV
- Generate PDF business reports
- View top-selling products
- Customize dashboard sections
- Analyze filtered business data

---

## 🎯 Objectives

The main objectives of this project are:

1. To build an interactive Business Intelligence dashboard.
2. To analyze sales data using meaningful KPIs.
3. To visualize business performance using charts.
4. To provide filtering and search capabilities.
5. To support CSV-based data import.
6. To provide CSV and PDF reporting features.
7. To identify top-performing products.
8. To store and manage sales data using PostgreSQL.
9. To integrate frontend, backend, database, and analytics functionality.
10. To create a professional and responsive dashboard suitable for real-world business analysis.

---

## ✨ Key Features

### 📌 KPI Dashboard

The dashboard displays important business metrics such as:

- 💰 Total Sales
- 🧾 Total Orders
- 📦 Total Quantity Sold
- 📊 Average Sale Value

The KPI values automatically update when filters are applied.

---

### 📊 Sales by Category

A bar chart displays total sales for each product category.

Example categories:

- Electronics
- Furniture
- Accessories

This helps identify which categories contribute the most revenue.

---

### 🌍 Sales by Region

A doughnut chart displays sales distribution across different regions.

Example regions:

- Chennai
- Madurai
- Coimbatore
- Tirunelveli

This helps understand regional business performance.

---

### 📅 Monthly Sales Analysis

A line chart displays sales performance over time.

The monthly sales chart helps identify:

- Sales growth
- Sales decline
- Monthly trends
- High-performing months

---

### 🏆 Top-Selling Products

The dashboard automatically calculates and displays the top 5 products based on total sales revenue.

Each product includes:

- Ranking
- Product name
- Sales progress bar
- Total sales amount

---

### 🔎 Search

Users can search sales records using the product name and other available information.

The search works together with the dashboard filters.
